# 💬 Chat App UI – Figma Design

This project contains the UI/UX design for a modern chat application created in Figma.
It focuses on clean layout, message readability, and simple user interactions.

## 📄 Pages Included
- Login / Signup
- Chat List
- Chat Screen
- User Profile
- Settings

## 🎨 Design Focus
- Minimal and modern UI
- Clear message hierarchy
- Consistent spacing and components
- Mobile-first layout
